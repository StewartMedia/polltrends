Method

Search interest. Daily Google Trends interest for each party's topic entity (not a single keyword), for Australia and for Victoria, over the last 90 days. Google scales each series 0–100 against the busiest day in the window, so values compare parties within a snapshot, not across days. Today's partial day is excluded. Interest measures attention, which can be positive or negative. It is not support.

Spikes. A day counts as a spike when a party's interest is at least twice its trailing 7-day average and at least 3 points above it. Back-to-back spike days collapse to the peak. Each spike is matched to headlines collected from Google News within a day either side.

Polls. Published Victorian voting-intention polls are read each day from the public record on Wikipedia, which links every figure to its original report. The average uses the latest poll from each pollster in the last 30 days, weighted equally. The two-party average only uses polls that publish a Coalition–Labor figure.

Seat model. The swing is Labor's 2022 two-party vote (55.0%) minus the poll average. It is applied evenly to every seat that was a Labor–Coalition contest in 2022, using the published pre-election pendulum. Seats contested against the Greens or independents are held constant. This is a transparent reference point, not a forecast; the published MRP is shown beside it because One Nation's vote breaks the two-party assumptions.

Briefing. These paragraphs are assembled from the computed figures by fixed rules. No language model writes or edits them.

Code and data. Every snapshot is committed to the project repository, so any figure on this site can be traced to its source file.
